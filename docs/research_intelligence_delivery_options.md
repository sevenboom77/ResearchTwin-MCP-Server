# Scheduled intelligence delivery options

| Option | Use | Recommendation |
|---|---|---|
| Bailian Workflow scheduled trigger | Generate and persist a Brief | First choice |
| SchedulerX + Bailian/OpenTrek Agent | Schedule an Agent and later add notification | Validate product integration first |
| SchedulerX HTTP/Webhook | Deliver results to an external channel | Bind only after the target channel is confirmed |

Notification transport is intentionally outside this repository. No webhook, email, chat, or push channel is hard-coded.
